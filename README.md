# Prosafety – návrhy nového webu

Statické návrhy domovskej stránky prosafety.sk (návrh A a návrh D).

- `index.html` – rozcestník s oboma návrhmi
- `a/index.html` – návrh A (Nočná stavba)
- `d/index.html` – návrh D (Signálna žltá)
- `img/` – logo a fotky

Web je čisté HTML a CSS s malým skriptom na mobilné menu. Nepotrebuje build ani server.
Stránky majú `noindex`, aby návrh v Google nekonkuroval súčasnému webu. Pri spustení ostrého webu tento riadok odstráň.
